# POScenter Files: удобные папки и массовая загрузка

Версия **1.1.1**. Публичный репозиторий Jeronimo701.

[Установить или обновить в Tampermonkey](https://raw.githubusercontent.com/jeronimo701/Poscenter-file-catalog-plus/main/Poscenter_file_catalog_plus.user.js)

Рекурсивный поиск файлов и папок в текущем разделе либо во всём хранилище fs.poscenter.org, массовая загрузка, предпросмотр и копирование ссылок.

## Автообновления

В скрипте настроены @updateURL на небольшой файл Poscenter_file_catalog_plus.meta.js и @downloadURL на актуальный .user.js из main. Адреса не привязаны к версии или коммиту. Репозиторий открыт, вход в GitHub не требуется.

Если ранее установлена приватная копия с @updateURL none, один раз установите скрипт по ссылке выше либо замените его содержимое и сохраните. Сохранены @name и @namespace. Проверка обновлений должна быть включена в настройках Tampermonkey; период проверки зависит от настроек расширения. Установленный экземпляр Tampermonkey автоматически в этой публикации не изменялся.

## Следующее обновление

Обновите .user.js, увеличьте @version, выполните `python tools/sync_meta.py` и отправьте оба файла одним коммитом. После этого Tampermonkey сможет обнаружить новую версию по прежнему адресу.

Версия 1.1.1 перенесена из файла владельца без изменений тела скрипта; добавлена только публикационная часть заголовка. Проверены синтаксис JavaScript, отсутствие секретов в текущих файлах и всей истории, публичная доступность и точность raw-файлов. В рабочей вкладке fs.poscenter.org сценарии поиска/скачивания не запускались.
